# Exact model

An **exact model** is a model that retains the exact data — the identity
preserving, fully decorated model, such as the exact `ProgramSlice` model, which
deliberately keeps wires present unchanged rather than collapsing them.  It is
the [[finite model]] on which exact statements are made, and it is the carrier
side of the [[exact carrier]].

An exact model is distinguished from a quotient or coarse model and from a
[[declared model]], which need not retain full data; exactness means no wire,
occurrence, or decoration is silently dropped.

# 精确模型

**精确模型**是保留精确数据的模型——保持身份、完整装饰的模型，如精确 `ProgramSlice` 模型，它有意
保留未改变的线而非坍缩它们。它是作出精确陈述所依据的有限模型，是精确载体的载体一侧。

精确模型区别于商或粗模型，也区别于不必保留完整数据的声明模型；精确意味着没有线、出现或装饰被
悄悄丢弃。
