# Temporal order

The **temporal order** of a process is its chronology — the order of its events
in time, declared as a target sort and distinct from the [[causal order]] (which
follows from dependence), the [[occurrence order]] (which follows from
occurrence), and the [[event order]].  Temporal order is irreversible evidence
extension: it records the order in which evidence accrues.

The temporal order generates the spatial opens and can be reconstructed from the
spatial family alone, so the two sides carry one chronology.

# 时间序

过程的**时间序**是其时间顺序——事件在时间中的次序，作为目标排序声明，区别于因果序（随依赖）、
出现序（随出现）与事件序。时间序是不可逆证据扩张：它记录证据累积的次序。

时间序生成空间开集，且能单独从空间族重建，故两侧携带同一时间顺序。
