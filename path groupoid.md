# Path groupoid

The **path groupoid** is the groupoid whose objects are the values (points) of a
model and whose arrows are the [[evaluation history|evaluation histories]] between them.  It packages
the noncommutative calculus of histories: endpoints may coincide while arrows
remain distinct, and loops encode relations among histories.

The [[accumulative commutative space]] is the abelianization of this
noncommutative calculus, keeping only the [[total charge|total charges]]; the [[torsion]] and its
[[area formula|area formulas]] quantify what is lost.  The path groupoid is one of the competing
sources for the [[history group]]'s [[assignment]] (free category, action groupoid,
path groupoid, rewriting 2-category).

# 路径群胚

**路径群胚**是以模型的值（点）为对象、以其间的求值历史为箭头的群胚。它打包历史的非交换演算：
端点可重合而箭头保持不同，环编码历史间的关系。

累积交换空间是此非交换演算的阿贝尔化，只保留总荷；挠率及其面积公式量化所失。路径群胚是历史群
赋值的竞争来源之一（自由范畴、作用群胚、路径群胚、重写 2-范畴）。
