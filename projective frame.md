# Projective frame

A **projective frame** is an ordered projective basis — a marked set of points
in projective space that determines projective coordinates.  On the projective
line a marked unit (together with $0$ and $\infty$) is an ordered projective
frame; under $g\in\operatorname{PGL}_2$ the marked unit is transported, and a
frame is represented by a [[rational matrix]] up to scalar on its image.

In the AM/Bruhat carrier, matrix columns are an oriented projective frame, and
a bare local point is read as a projective frame, that is, as a [[literal history]].
Forgetting the frame is a genuine loss: framed addition [[transport|transports]] between
projective frames, while the frame-forgotten value is not
$\operatorname{PGL}_2$-equivariant.

# 射影框架

**射影框架**是有序射影基——决定射影坐标的一组标记射影空间点。在射影线上，带 $0$ 与 $\infty$ 的
标记单位是有序射影框架；在 $g\in\operatorname{PGL}_2$ 下标记单位被传输，框架由其上到标量的有理
矩阵表示。

在 AM/Bruhat 载体中，矩阵列是定向射影框架，裸局部点被读作射影框架（即字面历史）。遗忘框架是
真实损失：框架化加法在射影框架间传输，而框架遗忘后的值不 $\operatorname{PGL}_2$-等变。
