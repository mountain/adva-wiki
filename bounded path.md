# Bounded path

A **bounded path** is a path (word) that begins with a number — an initial value
— and therefore evaluates to a number, whereas a [[free path]] consists only of
operators and evaluates to a function.  A free path becomes a bounded path once
an initial value is attached.

In a concatenation only the first factor may be bounded; if it is, the result is
bounded, and otherwise the result remains a free path.  This is the legacy
terminology of the earlier manuscripts; the present series uses
[[marked spinal history]] with an initial accumulator for the bounded form.

# 有界路径

**有界路径**是以数（初始值）开始、因此求值为数的路径（词），而自由路径仅由算子组成、求值为函数。
自由路径一旦附加初始值就成为有界路径。

在拼接中只有第一个因子可有界；若其有界则结果有界，否则结果仍为自由路径。这是早期手稿的遗留
术语；现行系列用带初始累加器的标记脊历史表示有界形式。
