# Lifted history

A **lifted history** is a [[process history]] carried on a cover — a universal
cover, a [[branched cover]], or a higher sheet — where the full [[ordered history]]
is retained.  For a branched cover $y^2=P(x)$, a closed base loop can return
$x(T)=x(0)$ while its lift returns $y(T)=-y(0)$: the base state has returned,
but the lifted history has not.

The difference is recorded by the deck transformation, a [[history residual]]
invisible in the base quotient.  The lift keeps both the base samples and the
selected sheet values, and for a closed loop it reports a sheet multiplier
$\pm1$; this is the elementary monodromy of a branched [[double cover]].

A lifted history thus retains exactly the order and sheet data that the base
state forgets; it is the [[universal cover]]-level object on which a
process history is compared without first collapsing it to its endpoint.

# 提升历史

**提升历史**是承载在覆盖上（万有覆盖、分支覆盖或更高叶面）的过程历史，完整的有序历史在此得以
保留。对分支覆盖 $y^2=P(x)$，闭基环可返回 $x(T)=x(0)$ 而其提升返回 $y(T)=-y(0)$：基状态已
返回，但提升历史没有。

其差由覆盖变换记录，是基商中不可见的历史残差。提升同时保留基采样与被选叶面值，对闭环报告
叶面乘子 $\pm1$；这是二重分支覆盖的初等单值性。

故提升历史恰好保留基状态所遗忘的次序与叶面数据；它是万有覆盖层上的对象，过程历史在其上比较，
而不先坍缩到端点。
