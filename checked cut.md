# Checked cut

A **checked cut** is a cut (frontier) that has passed the Rust check — the
certified [[causal cut]] data from which downstream constructions derive.  The
[[carrier matrix profile]] is derived from checked cut data, and a correspondence is
stated over one checked cut.

A general [[cut checker]] and an independently checkable cut certificate remain
unsupplied; a checked cut is the already certified frontier on which a
[[checked carrier]] is built, read from a [[cut frontier]].

# 检查切割

**检查切割**是通过 Rust 检查的切割（前沿）——下游构造所派生的经认证因果切割数据。载体矩阵简介由
检查切割数据派生，对应关系在一个检查切割上陈述。

一般切割检查器与独立可检验的切割证书仍未提供；检查切割是构建检查载体所依据的已认证前沿，从
切割前沿读出。
