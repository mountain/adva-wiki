# Unit frame

A **unit frame** is the [[ordered frame]] that measures the representatives of a
presentation; it does not choose the quotient or a fundamental domain.  The
projective unit frame $(0,1,\infty)$ marks the affine chart with $0$ and
$\infty$ and fixes the scale with the third mark $1$; under
$g\in\operatorname{PGL}_2$ the marked unit is transported to $g(1)$.

The unit frame is distinct from the [[quotient descent]], which says which
histories are identified; a unit frame measures, and does not select a deck
kernel or fundamental domain.  It is the [[projective frame]] carrying the unit
mark, resetting which to $1$ is a frame normalization, not an invariant action.

# 单位框架

**单位框架**是度量展示代表的有序标架；它不选择商或基本域。射影单位框架 $(0,1,\infty)$ 以 $0$ 与
$\infty$ 标记仿射图、以第三标记 $1$ 固定尺度；在 $g\in\operatorname{PGL}_2$ 下标记单位被传输到
$g(1)$。

单位框架区别于商下降（后者说明哪些历史被等同）；单位框架度量，且不选择甲板核或基本域。它是
携带单位标记的射影框架，把其重置为 $1$ 是标架规范化而非不变作用。
