# Path inverse

The **path inverse** of a [[marked spinal history]] $\gamma=(g_1,\ldots,g_n)$ is
the functional word $\gamma^{-1}=(g_n^{-1},\ldots,g_1^{-1})$ obtained by
reversing the word and replacing each context by its functional inverse; it is
defined only when every $g_i$ acts as an invertible function on a declared
domain.

It must be kept distinct from mirror and temporal reversal: the mirror swaps
operand slots while retaining [[chronological order]], the temporal reversal
([[path reversal]]) reverses order while retaining the contexts, and the path
inverse does both the reversal and the [[functional inversion]].  The path inverse
need not have the same operation labels or admissible domain as the reversal.

# 路径逆

标记脊历史 $\gamma=(g_1,\ldots,g_n)$ 的**路径逆**是函数词
$\gamma^{-1}=(g_n^{-1},\ldots,g_1^{-1})$：反转词并把每个语境换成其函数逆；仅当每个 $g_i$ 在
声明域上作为可逆函数作用时才有定义。

它必须与镜像、时间反演区分：镜像交换操作数槽而保留时间顺序，时间反演（路径反演）反转顺序而
保留语境，路径逆则既反转又做函数取逆。路径逆不必与反演有相同的运算标号或容许域。
