# Declared model

A **declared model** is an explicitly declared [[finite model]] — the model against
which a check, a theorem, or a catalogue is stated.  The catalogue is the entire
declared finite model, not every possible program, and a [[model gap]] means the
supplied evidence excludes the whole declared model.

The computer checks the declared model, while an unspecified future interpreter
leaves an open residual; theorems are stated about the declared observation,
cellular, or [[affine model]].  It is distinct from a [[declared carrier]], which
declares only its directions, and from an [[exact model]], which retains full
data.

# 声明模型

**声明模型**是显式声明的有限模型——检查、定理或目录所针对的模型。目录是整个声明有限模型，而非
每个可能程序，模型缺口意味着所供证据排除了整个声明模型。

计算机检查声明模型，而未指定的未来解释器留下开放残差；定理是针对声明的观察、胞腔或仿射模型
陈述的。它区别于只声明其方向的声明载体，也区别于保留完整数据的精确模型。
