# Free path

A **free path** is a path (word) consisting only of operators, with no initial
value; it evaluates to a function, whereas a [[bounded path]] begins with a number
and evaluates to a number.  A free path becomes a bounded path once an initial
value is attached.

Free paths are the arrow labels of an action groupoid: concatenation gives
their multiplication, and each free path acts on the state set by evaluation.
This is the legacy terminology of the earlier manuscripts; the present series
uses [[marked spinal history]] for the marked sequential form.

# 自由路径

**自由路径**是仅由算子组成、无初始值的路径（词）；它求值为函数，而有界路径以数开始、求值为数。
自由路径一旦附加初始值就成为有界路径。

自由路径是作用群胚的箭头标号：拼接给出其乘法，每个自由路径经求值作用于状态集。这是早期手稿的
遗留术语；现行系列用标记脊历史表示标记的顺序形式。
