# ACS path

The **ACS path** of an add–scale history is the path in the
[[accumulative commutative space]] $\mathcal A=\mathbb R^2_{(A,M)}$ traced by its
accumulating charge — the same object as the [[charge path]] $C_\gamma$: an
oriented polygonal path from the origin to the [[charge endpoint]]
$(A_\gamma,M_\gamma)$, whose successive segments are the horizontal $A$-runs and
vertical $M$-runs of the steps in [[chronological order]].

The ACS path is order-sensitive, while its endpoint is order-insensitive; the
$dM$ component changes under horizontal [[transport]], so the [[multiplicative charge]]
is not constant along the path.

# ACS 路径

加减历史的 **ACS 路径**是其在累积交换空间 $\mathcal A=\mathbb R^2_{(A,M)}$ 中由累积荷描出的路径——
与荷路径 $C_\gamma$ 同一对象：从原点到荷端点 $(A_\gamma,M_\gamma)$ 的有向折线路径，其相继线段是
各步按时间顺序的水平 $A$ 段与竖直 $M$ 段。

ACS 路径对次序敏感，而其端点对次序不敏感；$dM$ 分量在水平传输下改变，故乘法荷沿路径不恒定。
