# Research programme

A **research programme** is a conjectural research synthesis and
experiment-routing document: it records which unifying possibility a project is
deliberately testing, and why its apparently distant research lines belong to
one programme.  It is not a theorem, not a theory-promotion record, and not a
public API contract.

The central wager of the process-geometry programme is arithmetic generativity
— that arithmetic primitives, their free compositions, and their objectified
higher-rank operations generate geometry, calculi, information, complexity, and
new [[process rank|process ranks]] — and the scope question of arithmetic
universality is an active direction, not an assumption.  When the programme and
the mathematical core disagree in strength, the proof artifacts and the core
determine what has been earned; the programme determines neither maturity nor
API status.

# 研究计划

**研究计划**是猜想式研究综合与实验路由文档：它记录一个项目正在有意检验的某个统一可能性，以及
其看似遥远的研究线索为何属于同一计划。它不是定理，不是理论晋升记录，也不是公共 API 契约。

过程几何计划的中心赌注是算术生成性——算术原始、其自由复合及其对象化的高秩运算生成几何、演算、
信息、复杂性与新的过程秩——而算术普适性的范围问题是一个活跃方向，而非假设。当计划与数学核心
在语言强度上不同时，证明工件与核心决定已经挣得什么；计划既不决定成熟度也不决定 API 状态。
