# Event rank

The **event rank** of a witness or event is its history index — its position in
the [[ordered history]], distinct from the [[event order]] it records and from the
[[process rank]] of the whole process.  Inserting earlier events into the
contact alphabet shifts the event rank by a constant (e.g. $+2$), while the
witness boundary and mode stay fixed; this is [[history reindexing]], not observer
motion.

Dropping event rank is a genuine loss: the objectified task loses exactly eight
coordinates when event rank is removed, and the event-rank-free boundary task is
the coarser projection.

# 事件秩

见证或事件的**事件秩**是其历史索引——它在有序历史中的位置，区别于它所记录的事件序与整个过程
的过程秩。向接触字母表插入更早的事件使事件秩平移常数（如 $+2$），而见证边界与模式保持固定；
这是历史重索引，而非观察者运动。

丢弃事件秩是真实损失：对象化任务在移除事件秩时恰失去八个坐标，事件秩自由边界任务是较粗的投影。
