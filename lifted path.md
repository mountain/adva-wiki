# Lifted path

A **lifted path** is a path (curve) on a cover — a [[branched cover]], a Riemann
surface, or a higher sheet — obtained by lifting a base path and recording the
sheet it occupies.  Two projected paths may meet at the same base point while
their lifted paths lie on opposite sheets, so such a meeting is not an
intersection on the cover.

A lifted path carries the sheet data that the base path forgets; on a genus-$g$
carrier it carries the raw Abelian-integral increment along the path, and its
[[lifted path holonomy]] records what the base forgets.  Closure of the base path
does not imply closure of the lifted path: a closed base loop may return on the
opposite sheet.  The lifted path is the geometric object on which the
[[lifted history]] of sheet choices is read.

# 提升路径

**提升路径**是覆盖（分支覆盖、黎曼面或更高叶面）上的路径（曲线），由提升基路径并记录其所在叶面
得到。两条投影路径可在同一基点相交而其提升路径位于相反叶面，故这样的相遇不是覆盖上的相交。

提升路径携带基路径所遗忘的叶面数据；在亏格 $g$ 载体上它携带沿路径的原始 Abel 积分增量，其提升
路径和乐记录基所遗忘者。基路径的闭合不蕴含提升路径的闭合：闭基环可在相反叶面返回。提升路径是
读出叶面选择的提升历史的几何对象。
